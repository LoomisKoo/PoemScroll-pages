诗画卷：走进每一首诗的画里。四十五首古诗，每首一幅会动的纸雕画卷，点哪里都会动。

联系我们

遇到问题或有建议，请发邮件到 magaxy@163.com，并附上你的 iPadOS 版本与设备型号，我们会尽快回复。

怎么玩

  1. 首页按「四季 / 朝代 / 作者」切换书架，点封面进入画卷。
  2. 点画里的东西——树、人、船、云、月亮，都会各自动起来。
  3. 右下角是诗句卡片，点其中一句就能听到朗读；点右上「诗解」看释义、注释与赏析。

常见问题

没有声音 / 念错字？

朗读用的是 iPad 系统自带的中文语音，不需要联网。若无声，请检查侧边静音开关与音量；系统没装中文语音时，可在 iPadOS「设置 → 辅助功能 → 朗读内容 → 声音 → 中文」下载。

为什么只有 iPad 版本？

画卷是 4:3 的横向构图，手机上会被裁掉上下大半，所以只做了 iPad 版。iPad 请横屏使用。

需要联网或登录吗？

不用登录，看诗也不需要联网：全部诗画、配音与讲解都在本机，无账号、无广告，也不收集你的任何信息。只有购买 Pro、恢复购买和查看隐私政策等网页时会用到网络，这些请求由 Apple 或 GitHub 处理。

哪些内容免费？

《春晓》和《咏鹅》两个场景可以免费看。其余画卷属于「诗画卷 Pro」，一次买断即可全部解锁，不是订阅。「设置 → 恢复购买」可以在新设备上找回已购买的解锁。

买了打不开 / 换设备怎么办？

先用同一个 Apple ID 登录 App Store，再打开「设置 → 恢复购买」。若仍不行，请确认网络通畅后重启 App 再试；还有问题请发邮件到 magaxy@163.com。

画面卡顿？

场景用 Metal 绘制。若在较旧机型上掉帧，可先把其他 App 关掉再打开；切到别的应用时场景会自动暂停。
